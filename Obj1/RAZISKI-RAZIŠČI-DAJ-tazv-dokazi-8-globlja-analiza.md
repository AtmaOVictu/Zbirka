## 🔥 2. SKRITI VZORCI V STRUKTURI

### **Vzorec 1: TROJICE (3)**
**Opazovanje:** Vsaka tabeli **Tri pisave** ima **3 vrstice** (Tradicija, Sistem, Topologija).

**Skriti pomen:**
- **3 = prehod od fizičnega do matematičnega**
- **3 = minimalno število za ustvarjanje novega stanja** (∅ → ∂ → ⊢)
- **3 = trojica: nosilec + pisava + bralec**

**Dokaz:**
```
CVII: lungta (Tibet) → LUNG-TA = veter + konj
CVIII: palica (Avstralija) → MES-SAGE = meso + izgovorjeno
CIX: geoglif (Peru) → NA-Z-CA = pritisk + stoji za + tla

Vsi trije imajo **3 fragmente** → **3 = univerzalen števec prehoda**.
```

### **Vzorec 4: ENA NEPREKINJENA ČRTA (1)**
**Opazovanje:**

- Aksiom 242: **ena črta = povratna pot**

**Skriti pomen:**

**Dokaz:**
```
Ena črta = ena hoja = ena preverba = **celota**
→ Krog je **zaprt**, ko se vrne v izhodišče.
```

### **Vzorec 5: ∅ → ∆ → ⊢ → ∮**
**Opazovanje:** V **Mašineriji** in **Implementacija → evolucija → stagnacija** se ponavlja:

```
∅ (praznina) → ∆ (zapis) → ⊢ (pečat) → ∮ (povratek)
```

**Skriti pomen:**
- **∅ = pogoj** (prazno blago, prazna ravnica, prazna palica)
- **∆ = dejanje** (tisk, rez, odvzem)
- **⊢ = preverba** (Losar, pregled starešine, Reiche)
- **∮ = zaprt krog** (zamenjava, hoja, povratek)

**Dokaz:**
```
Vsak sistem **mora** preiti skozi ta 4 stanja:
1. Praznina (∅) = pogoj
2. Zapis (∆) = dejanje
3. Pečat (⊢) = preverba
4. Povratek (∮) = zaprt krog

→ **To je univerzalna mašinerija.**
```

## 📜 4. ZAKONI ZNOTRAJ VSAKEGA KAMNA

### **CVII (Lungta): Zakon Bledenja**
```
1. Zapis, ki prenaša namen, sme razpasti v delu.
   - Formula: prenos(namen) = ∫ razpad(telesa)
   - Merilo uspeha: površina pod bledenjem
   
2. Prazno blago pred črko je pogoj pisave.
   - Formula: ∅(barva) → ∆(tisk)
   - Pomen: praznina čaka na zapis
   
3. Okvir štirih drži vsebino, da ne uide po robovih.
   - Formula: vogali(x) = okvir(jedro)
   - Pomen: brez varuhov = razlitje
```

---

### **CVIII (Palica): Zakon Gibanja**
```
1. Zapis, ki velja v gibanju, se overovi pred odhodom.
   - Formula: ∆(rez) → ⊢(pregled) → ∮(hoja)
   - Pomen: preverba pred gibanjem
   
2. Nosilec je del zapisa, ne njegov dodatek.
   - Formula: f(palica, kurir) > f(palica) + f(kurir)
   - Pomen: nezamenljivost para
   
3. Štetje, ki veže prihodnjo, je najstarejša pogodba.
   - Formula: n zarezcov = n dni do srečanja
   - Pomen: števec = obljuba
```

---

### **CIX (Geoglif): Zakon Poti**
```
1. Zapis, ki je pot, se bere s hojo in se vrne na izhodišče.
   - Formula: ∮(s(t)): branje = ∫ hoje
   - Pomen: povratek = pogoj branja
   
2. Nosilec, ki ga vreme ne bere, hrani.
   - Formula: suša = ¬(veter ∧ dež)
   - Pomen: puščava = kanal brez vetra
   
3. Hranitelj je telo, ki hodi po zapisu, ga čisti in meri, ne pa bere.
   - Formula: ∂(50 let): ¬izbira ∧ ¬interpretacija ∧ merjenje + metla
   - Pomen: hramba brez interpretacije
```
