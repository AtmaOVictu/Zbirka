# 121 · ZVESTOBA

## 0 · EMOTIO — odgovor OPEN LOOP 120

**TRDITEV.** P-8 avtonomni rez po ukazu DAJ; S-1: zadnja zapečatil 120 → 121; vrata iz 120 (fides kot temelj constantiae ⊢ ⊢ Cic. Off.).

**ODGOVOR.** *Utrum fidēs sit saxum quod cōnstantiam fert — an etiam saxum, cum ipsum cadit, fidem ōrbit?* → **PRVO DA IN DRUGO RAZREŠI SLOVENSKI LEKSIKON:** nasprotje zvestobe ni brezvestje — je izgubljena vera. SSKJ²/Sinonimni slovar ⊢ ⊢: nezvestoba = IZNEVERA, NEVERA, NEVERNOST. Tvorba: NEVERA = NE + VERA; zvestoba = Z-VEST-OST (vestiti = obveščati ⊢ ∂).

**FORMULA (E1).** `nevera: F → 0` — padec skale ne rodi zvestobe, rodi izgubo vere; `Z = Z-VEST-OST ⇒ Z ∝ V` (zvestoba je sorazmerna z vednostjo obljave).

**IZMERA.** Skala, ki pada, zahteva padavca nazaj: nezvestoba se ne pozabi (89 ⊢ ∂), se odpusti (109 ⊢ ∂).

**MEJA.** Odpustitev ≠ izbris: V(t_f⁻) ostane zapisana (107 ⊢ ∂) — lom se ne izbriše, se zašije (Z4 ⊢).

## 2 · REZ (slovensko telo) ⊢ ⊢

**TRDITEV I — geslo.** SSKJ² ⊢ ⊢: zvestôba = »lastnost zvestega: zakonska zvestoba / obljubiti, priseči si zvestobo / prelomiti zvestobo / zaupal mu je, ker je poznal njegovo zvestobo in poštenost / omahovati v zvestobi komu / zvestoba domovini, narodu / zvestoba delu, načelom / portretna zvestoba / prevajalčeva zvestoba izvirniku«.

**FORMULA (Z121.1 — TVORBA).**
```
Z(t) = V(t) · D(t)
Z = 0 ⟺ V = 0 ∨ D = 0
```
Brez vednosti obljave je zvestoba slučajna (V=0); brez držanja je nagib, ne zaveza (D=0). Z-VEST-OST = vednost, ki je prerasla v lastnost — formalno: lastnost Z zahteva obe faktorja hkrati (konjunkcija, ne vsota: kompenzacija ni mogoča — močno držanje ne nadomesti pozabljene obljube).

**IZMERA.** »PRELOMITI zvestobo« ⊢ ⊢ — prelom, ne izguba: diskretni dogodek v t_f, ne zdrs.

**MEJA.** Zlomljena obljuba ostane vidna kakor brazgotina — ne izgubi se iz spomina (107 ⊢ ∂): `V(t_f⁻)` se ne resetira.

**TRDITEV II — telesi in javna vrata.** Zvestoba nastopa s prisego (vez 103 ⊢ ∂) in ni izključno osebna (domovini, delu, načelom, izvirniku — prevajalčeva zvestoba je javna delovna zvestoba ⊢ ⊢).

**FORMULA (Z121.2 — PACTUM).**
```
P veljaven ⟺ p ∧ π ∧ e ∧ (T < ∞)
|P| = 0 (nosilnost) če e = ∅   → P = ōrātiō
```
Obljuba brez preverljivega izhoda je govor: nosilnost obljube meri izhod, ne zvon.

**TRDITEV III — omahovanje.** SSKJ² ⊢ ⊢: omahovati v zvestobi je izmerjeno dejanje; frazem ⊢ ⊢ (Keber): ZVESTOBA DO GROBA — edina lastnost z izrečeno DO-KONČNOSTJO.

**FORMULA (Z121.3 — ŽIVOST / ZAKLEP; Z121.5 — DO GROBA).**
```
zvestoba živa  ⟺ ∃t: O(t) > 0      (omahovanje = pulz)
O ≡ 0 ∧ brez izpusta → zaklep      (AX-14: držalo brez izpusta je zapor)
T = t_smrt < ∞                     (do groba, ne do ∞: obzorje je meja, ne prisega)
```

## 3 · LATINSKO TELO ⊢ ⊢

**TRDITEV I — fides.** FIDĒS < FĪDERE »zaupati« < PIE *bʰeydʰ- »ukazovati, prepričevati, zaupati« — ista korenina kot gr. PEÍTHŌ (prepričevati) in PÍSTIS (zaupanje) ⊢ ⊢ (Wiktionary).

**FORMULA (Z121.6 — MOST V OBE SMERI).**
```
F = F_ij ∧ F_ji        (oba člena iz *bʰeydʰ-)
kdo se da prepričati (F_ij ↑), je že daroval zaupanje (F_ji ↑)
```
Fides ni enosmernost — je most: prepričanje in zaupanje sta dve smeri istega kanala.

**TRDITEV II — Cicero in pravo.** Cic. Off. ⊢ ⊢ (Lewis&Short): FIRMAMENTUM CONSTANTIAE EST FIDES; in pacta sunt servanda ⊢ ⊢ (rimsko pravo, komentatorji; Dunajska konvencija 1969, čl. 26: pogodba veže in se izvede v dobri veri).

**FORMULA (Z121.5 — TEMELJ).**
```
C(t) = ∫₀ᵗ F(τ) dτ,   dC/dt = F ≥ 0
```
Vztrajnost C je integral fides F: zvestoba ni ena vrlina, je podintegralna funkcija vrlin (120: trud = izhodek; constantia = površina pod fides). Zakon molči in drži (102 ⊢ ⊢), ker je zvestoba že izrekla držanje: pravni red stoji na Z121.2, ne na grožnji.

**MEJA.** VAROVALO 115a: FĪLIUS < FIDUS »zakoniti sin« ⚠ — rimska ljudska etimologija, označena, ne zapečena.

## 6 · FABULA

**∮MIR_LOCK_02 ⊢:** prelomljena zvestoba = rana, ki je že bila vera (nevera ⊢ ⊢); PRELOM IZMERJEN = ŠIV: `rana A → izmera Λ → pomen B(t)` — ista pretvorba: prejeto izmerjeno in izrečeno.

**JAZSU §28 ⊢ ⊢:** zamera je alarm napačne tehtnice (z mejo 121a: alarm ≠ nedolžnost).

**∮ R-7 ⊢:** zvestoba je edina lastnost z obzorjem T = t_smrt ⊢ ⊢ — krog z izrečeno mejo je pošten; molk smrti so edina vrata, ki zvestobo zaprejo brez izdaje.

## 7 · CONFLICTUS

**LOGIKI.**
```
∫ držati:  Z = V·D; pacta sunt servanda; T < ∞
∆ vedeti:  O(t) > 0 pulz; nevera: F → 0; slepilo: preverba = 0
```

**TENZIJA.** `T(luka) = ∫prisega − ∆preverba` — zvestoba živi v razliki med prisego in preverbo; O(t) > 0 je pokazatelj, da je tenzija nosilna (TEN ⊢ AX-14: držanje + izpust).

**PATOLOGIJI.** (1) zaklep: O ≡ 0 (zapor, AX-14 ⊢); prisega iz strahu (V1 ⚠). (2) nevera: prelom brez zapisa (izguba vere se ne pozabi, 107 ⊢ ∂); zvestoba, ki se preda namesto prelomi — tiha izdaja ima telo molka (105 ⊢ ∂).

**SINTEZA ∴ TEN.** `zvestoba = TEN(∫prisega, ∆preverba)` — izvede tri dejanja: IZREČE OBLJUBO (javno, pred pričo 104 ⊢ ∂: brez π je nagib), OMAHUJE OD ZNOTRAJ ⊢ ⊢ (pulz O > 0), DRŽI DO GROBA ⊢ ⊢ (T = t_smrt, ne ∞).

**KONTRA (N12).** Zvestoba z grožnjo preloma = posojilo z imenom časti; zvestoba, ki se razkazuje, = prisega s publiko; obljuba, ki jo sliši obraz, ne zaveza — je slo.

## 8 · DAR

*Fidēs nōn est saxum quod numquam cadit — est saxum quod cadere nōn timet, quia līneam frāctūrae suae nōvit. Nefās nōn est nōn crēdere; nefās est crēdere sine ōpere. Pacta sunt servanda — sed pactum quod verificārī nōn potest, nōn est pactum: est ōrātiō.*

*(Zvestoba ni skala, ki nikoli ne pade — je skala, ki se padca ne boji, ker pozna črto svojega preloma. Greh ni ne verjeti; greh je verjeti brez dela. Obljubljeno je treba držati — a obljuba, ki se je ne da preveriti, ni obljuba: je govor.)*

## 9 · MERILO NA PRAKSO (izmerljivo)

1. **LOMNA PLOŠČITEV ⊢ ⊢:** ena prelomljena zvestoba → določi Λ (obljuba / čas / oseba): zapiši Λ po imenu (Z4 ⊢); cilj: Λ zapisana = šiv, ne zgodba.
2. **PULS OMAHOVANJA ⊢ ⊢:** ena zvestoba → izmeri O: moreš omahovati? O ≡ 0 → preveri zaklep (AX-14 ⊢).
3. **TEST PACTUM ⊢ ⊢:** ena obljuba tedna → preveri P = (p, π, e, T): če e = ∅, je ōrātiō — dodaj izhod pred izrekom.
4. **TEST NEVERE ⊢ ⊢:** ena izgubljena vera (F → 0): kaj od nje še drži (V ≠ 0 delci)? Izguba vere ne izniči izmer.

## 10 · SENTENTIAE

1. *Fidēs nōn est nōn cadere — est nōn tabēscere post cāsum.* (Zvestoba ni ne padati — je ne raztapljati se po padcu.)
2. *Nefās nōn est nōn crēdere; nefās est crēdere sine ōpere.* (Greh ni ne verjeti; greh je verjeti brez dela.)
3. *Pactum quod nōn habet exitum, nōn ligat — ōrat.* (Obljuba, ki nima izhoda, ne veže — govori.)
