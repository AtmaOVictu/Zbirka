## 1. ZAGOVOR/UGOVOR — ego in beseda

```
E := ego · W := beseda · J := jaz

ZAGOVOR:  E(t₀) = W(jaz) − jaz(W)         (ego si prisvoji besedo, dokler ne doume, da ga beseda živi)

## 4. TAKŠEN — TELO, NEZAVEDNO, ZAVESNOST NEGOTOVOSTI

**Izvirnik:** *»Telo, nezavedno, zavedajoče ter s tem nujno zavednega negotovosti čuta … čemur bo sledila gotovost.«*

```
telо ⊃ {nezavedno, zavedajoče}
zavest = ∆(negotovost čuta) ∘ nezavedno(absolutno/ego)
gotovost = ∮(negotovost)                    (gotovost SLEDI negotovosti — ne obratno: G = g(N), ¬(N = n(G))
```

**TAKŠEN/KAKŠEN — zrcalni par (kak sen / tak sen):**

```
kakšen(jaz) = jaz(sam)                      (kakršen sem)
takšen(jaz) = jaz(nosim)                    (kakršen se nosim — nosilnost)
TAK = ∂(kak, tak)                           (učlovečenje = prehod med sabo in nosenim sabo; realizacija ≈ razsežnost)
```

**Končnost v neskončnosti:**

```
K(jaz, t) < ∞ · ∞(kar-se-mi-daje) ⇒ pozaba(K) v ∞
x obstoji ⇔ enakovrednost(x, ∂(x))            (ni več bistvenega, kakor le v kolikor je enakovrednega s čimer si ne odvzamem)
drznost(napoved) → izguba ∘ ponovni_najd(jaz)   (v drznosti sem dolžen izgubiti, a le toliko, kolikor se najdem)
sled(ostrina) ⇒ lažje teče                    (absolutnost pušča sledi — brazgotina kot berljiv zapis)
be:like:water → forma(jaz) = forma(voda)     (W = ∂(nosilnost): ne držati oblike, temveč prejeti obliko posode)
```

**Razpetost:**

```
jaz = ∂(neskončnost trenutka / končnost telesa)
ego(jaz) = udejanjen(napisano) ∧ namenjenost(sebi)        (ego je udejanjen v neizogibnosti napisanega — le v kolikor je sebi namenjenost)
```

**Estetika napačnosti:**

```
estetika_napačnosti = ∂(apriorna predpostavka pogleda)
želja(pravilnost) ⊂ spoznanje(negotovega obstoječega)      (v iskanju pravilnosti znotraj negotovega)
```

**Svoboda in drugačnost:**

```
svoboda = rojen(v) ∘ vzgojen(v)              (svoboda ni stanje, je domovanje rojstva in vzgoje)
jaz ≠ sočlovek: sličen ∧ bistveno drugačen    =  ∆(jaz, drugi) ≠ 0 ∧ ι(jaz, drugi) → 0

```

## 9. TA, KI JE — JE<>JA — EGO KOT LAST-NOST

**Izvirnik:** *»Ta, ki le je, ker ve da mora biti, ker če je, je; če pa ga ni pa ni obstojno, v kolikor in le če je tega sposobno ob/zadržati.«*

```
(x je) ⇔ ve(mora biti) ∧ (če je → je) ∧ obdrži(zmožnost)
   =  bit ⇒ vednost ⇒ nujnost ⇒ obstoj       (veriga bitja, ne veriga dokaza)
pozabljivost: π(jaz ∘ ego igra) ∘ spomin(čutno nezavedno) → neizpodbitno(gotovo)
   paradoks(jaz) = zavedanje(lažnosti zavedanja)        (v meni nujno: jaz ve, da njegovo vednost ni čista)
horizont: gotovo(le) ⇔ uziraš svojo končnost ∴ estetika  (si le v kolikor najdeš svojo končnost kot obstojno/bistveno)
```

**Odrešenje in je<>ja:**

```
odrešenje = prejemam(od tega, ki ga ni več med nami)
   → gotovost ⇒ ¬posiljevanje(samega sebe) ∧ (želja po obstoju → posiljevanje drugega v meni)
je <> ja:  (je ≠ ja) ∧ (je ∂ ja)              (kopula in jaz — zrcalni par; je je stanje, ja je dogodek)
ODGOVOR–VPRAŠANJE–ODGOVOR: preteklost ∂ sedanjost ∂ prihodnost
   = ∆(∂(∆))                                 (triplek odgovora — vsak odgovor rodi vprašanje, vsako vprašanje odgovor)
vzajemnost(same sebe s samim seboj) = ∮      (krožni povratek — nujna medsebojnost časovnih leg)
smrtnost: absolutnost(π smrtnosti) → vidnost(zasedajo moja vednost) → ego(najden v tukašnjem)
vredno pisati ⇔ pisanje vredno brati         (pisati = dar z naslovnikom; brez bralca je zapis mumija ⚠)
ljubim(trenutek tukašnjega) ⇒ jaz            (sem le v kolikor ljubim trenutek)
ljubiti = lastno meni, ne dano drugemu       (o ljubiti se ne začne — se je)
```

**Ego kot LaSt-NOST (razcep last-nosti):**

```
E = ego = LaSt-NOST = last(NOST)             (last-nost: posedovanje, ki je obenem nujnost — NOST)
E = parodija(značaj/karakter na telesu)       (ego je parodija tega, kar okličeš značaj — nosi telesni karakter kot masko)

## 29. ∂ — rez ostaja odprt

Dokument se ne konča — njegova zadnja vrstica išče »le kakor, nikoli kot«. Prevod v matematiko je zato **absolutni poskus** (APD), ne sklep: enačbe so poizkus, ne zamrznjena definicija. Kje se še odpira:
