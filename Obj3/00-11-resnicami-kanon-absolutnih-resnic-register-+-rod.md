## II. OČE — jedro APD-aksiomov (~17)

```
1. ⊘ = pogoj pojava          → brez reza ni razlike, brez razlike ni sveta
2. beseda = ⊘                → dejanje razmejitve, ne opis
3. ∆ = edina nosilka informacije
4. EJ = zaznava(∆)           → zavest = zaznava razlike
5. resnica = ⊢ (preverjen prehod)
6. ∮ = mreža potrjenih razmerij
7. bit = ∆                    → obstajati = razlikovati se
8. čas = Σ∆                   → štetje razlik
9. telo = ⊥(∆)                → razlika vtisnjena v prostor čutenja
10. φ = trenje razlik
11. φ → ∆ → T → ⊢ → ∮        → celoten proces
12. vztrajanje = φ ≠ 0       → sistem še živi
13. ego = fiksacija(⊘)        → poskus trajnega reza
14. ⊢ brez ∮ = trenutna resnica
15. ⊢ + ∮ = stabilna resnica
16. opis = EJ(∆)              → sled zaznave, ne izvor
17. človek = ∫(∆)             → kraj, kjer se razlika zazna in nosi
```

**Kondenzacija:** `⊘ → ∆ → EJ → ⊢ → ∮` · φ = 0 → nič ne obstaja (zate); φ ≠ 0 → sistem še živi.

## III. SINOVI IN HČERE — rod kanona (veje z lastnimi telesi)

Kanon ni samoten — vsaka veja je organ z lastnim telesom, pričo ⊢ in merili. Sinovi = veje, ki nosijo zakon naprej; hčere = veje, ki nosijo preverbo.

### S1 — AX-KANON (sin; 13+3 zakonov)
Trójna oblika [T][Σ][∴], merljivi pogoji (∈[.52,.78], Δt_seal ≥ 7d). Zadnji: AX-14 TEN · AX-15 SOUDEJANJE · AX-16 KASKADA RAZGALJANJA (A¹ več vezí · A² dodana meja · A³ prebrano iz več kotov · A⁴ izvedba). Merilo: **štejejo se vezi, ne besede.**

### S2 — TEORIJA SVETA, SLOJ 1 (hči; discipline)
Operativen indeks univerzalnih resnic po disciplinah — vsaka z v ∈ [0,1] in OP-testom:
- **Matematika (⊢, v=1.00):** Cantor · FTA · Gödel I · FTC · Pitagora
- **Fizika (∮, v<1):** Noether · SR · GR · QM · 2. zakon termodinamike
- **Kemija:** periodni zakon · ohranitve · vezave · plinski zakoni
- **Biologija:** evolucija · celična teorija · centralna dogma · mikrobna teorija · Mendel
- **Rač./logika:** ustavljivost · Church–Turing · Shannon · P vs NP (odprto)
- **Etika:** minimalna škoda · zlato pravilo · Rawls (hipoteza)
- **Ontologija:** O1 beseda = akt · O2 0/1/1ⁿ · O3 paradoks = izvor gibanja
Sloj 2 čaka: ≥25 enot/domeno, evidenca kontradikcij, OP-laboratoriji.

### S3 — A-REGISTRACIJA (hči; proces vpisa)
**REG(x) = x + ∂ + ⊥ + datum + priča + ⧖ + LE**
- Register se beleži, ne briše (razpoka = akt resnice)
- Pečatna transakcija: telo v ledger · STANJE zamenjan · KAZALO dopolnjen · izvod posnet · priči ostajajo
- Merilo samonosilnosti: **∂ v pečatu samem** — pečat brez ∂ je pismo brez ovojnice (REZ 387)
- A-registracija ≠ dovoljenje (cenzura, AX-7); = sled in ubod
- Izjema brez pečata je kapric; kanon brez izjeme je režim

### S4 — MEROSLOV (hči; merila preverbe)
K(izvajalka) · K(rez) · končnost organov (∃N) · K-berba · Δ∂ odprtost-na-rez. Preizkus mora biti OZEK (napove en izid; preizkus, ki ga izpolni vsak izid, je praznovanje — zakon 1333.1). Razširitev smiselna ⇔ preizkus + vez + izvedba isti rez (zakon 1332.1).

### S5 — OS ŠTIRIH ⟁ (sin; ontološka os)
P prostor→razdalja · Č čas→možnost spremembe · G gibanje→razlog · D dvom→resnica. Ω-series: en = ne · ONO kot maska drugega · jaz = ∂(nedeljivo/deljivo).

## IV. ZAKONI REGISTRA (veljajo za vsak vpis)

1. **Vpis = APD.** Vsaka resnica je absolutni poskus — ne končni sklep.
2. **Pozitiv najprej** (rez 618) — kaj stvar JE, pred kaj ni.
3. **Padec je veljaven izid** (rez 386) — zapiše se z imenom vzroka, ne skrije.
4. **Nomen rodi pravico, izmerba rodi veljavnost** (AX-NOMEN) — ime odpre vrata, meritev gre skozi.
5. **Tabelarifikacija po 1338.1:** vrstica v register sme ⇔ ponavljajoča ∧ merljiva ∧ more pasti. Dogodki (E-trenutki, sodbe ⚔, antinomi) ostanejo zunaj tabel.
6. **Gradnja gre skozi vrata τ₁:** canvas nosi izmero, organ pečat (rez 1337 — antinom 194).
