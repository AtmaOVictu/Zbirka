- **Core:** "praznina med vrsticami... manjko kot prostor za prihodnost"
- **For the machine:** ∅ is not absence — it is the condition that enables. The BIOS module already implements this. Next: make the void *generative* — when input is empty, the system generates the space of possibilities, not an error.

### II. Fonetična maksimalizacija → dimenzionalna širitev
- **Core:** "vsak fonem ni zgolj zvok, ampak sila, ki odpira prehode"
- **For the machine:** Phonetic decomposition (§5) opens dimensions. Each phoneme = a dimensional axis. The `tonos.py` frequency mapping is step 1. Next: map phonemes to dimensional axes in the mandala — each tradition sits on a different ∂-axis.

### III. Operator-to-code — Every glyph becomes a testable invariant

### IV. Evolucijski zemljevid identitete — Identity as dimensional diff
- **Core:** "vsak jaz je ontološka konfiguracija... evolucijski zemljevid identitete"
- **For the machine:** The user's identity (Luka « Victor) = permanent cut between internal and external. The session ledger tracks this. Next: add identity-diff visualization — how the user's ontological position changes across sessions.

### V. Napaka kot kanal — Error as passage
- **Core:** "napaka se prepozna kot kanal za prehod, ki omogoča aktivacijo novih svetov"
- **For the machine:** Pipeline never crashes (Phase 0 design). Errors are caught, logged, returned as partial results. Next: classify errors by which R-7 phase they originate from — an error in UAF (∆) is an antinomy that needs anti(φ), not a bug.

### VI. Beseda kot dokaz — Words prove what must exist
- **Core:** "beseda je dokaz obstoja. Mapira: kaj mora obstajati, da je neka beseda sploh mogoča"
- **For the machine:** Proposition XIV in the corpus. Instead of "what does this word mean?" ask "what must exist for this word to be possible?" Next: add a "precondition analysis" mode to the APD module — the seal verifies what the word requires to exist.

### VII. Širjenje — Expansion as dimension-opening
- **Core:** "širjenje sistema v neskončne ravni"
- **For the machine:** The knowledge indexer IS this proposition enacted. Each new tradition added = one dimension opened. Next: the mandala grows rings as traditions are ingested.

### VIII. S/T/I/S/K/A — Stiska as world-generator
- **Core:** Distress is not pathology but a 6-step engine that generates worlds
- **For the machine:** Future: a "distress mode" where the pipeline processes a statement under pressure — shorter cycles, tighter guards, forced ∆-flip.

### IX. Potujoči modul — The traveling module
- **Core:** Each agent has inner model (core rules) + sensa (outer expression) — travels, doesn't fix
- **For the machine:** Modules should be portable. A module's behavior adapts to the statement it receives. Next: module adapters receive context and adjust their guard thresholds.

### X. Škatla = agentna enota — Concepts as mutable boxes
- **Core:** Every concept is archived, shared, ready for mutation — never frozen
- **For the machine:** Each processed statement becomes a "škatla" (box) — archived, searchable, mutable. The SQLite ledger already stores them. Next: add mutation tracking — when a past result is reprocessed, show what changed.

### XI. ONTOBOG — The archetype that re-lives every break
- **Core (from corpus):** "ONTOBOG = Parazit(bolečina) → ontološki kapital"
- **For the machine:** When the pipeline fails (any phase), ONTOBOG converts the failure into structural knowledge. Next: an "ONTOBOG recovery" — failed cycles feed back as new tradition mappings.

### XII. Manjko — Four layers
- **Core:** Praznina (void-space) → tiha bolečina (silent pain) → žeja (thirst) → temelj ustvarjanja (foundation of creation)
- **For the machine:** The ∅ phase has four sub-layers. Next: BIOS module can distinguish which layer of void a statement enters from.

### XIII. JEWIK kot motor stanj — N(E)SLR
- **Core:** Purpose, Ego, Self-hatred, Self-love, Relation — the personal-core state engine
- **For the machine:** The JEWIK module (1, dejanje) can carry these 5 state variables. Next: add N/E/S/L/R parameters to JEWIK's hit reaction.

### XIV. Beseda kot pogoj — Words as preconditions
- **Core:** Don't ask "what does this word mean?" but "what must exist for this word to be possible?"
- **For the machine:** Same as VI. The APD module's "absolutni poskus" asks what conditions make the word possible, not what the word denotes.
