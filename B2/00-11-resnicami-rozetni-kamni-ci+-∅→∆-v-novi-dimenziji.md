## ∂ Vprašanja (61–66)

61. **Ali A₁ = ∅/∆ = binarni rez (Kamen LXXII)?** — Coxeter (CXXIV) najde A₁ = |S₂| = 2. Ali zrcaljenje = ¬, kot Bythos→Sige (CI)? In ali E₈ = Coxeter E₈ potrjuje Kamen XVI?

62. **Ali prime voz = ∅, Jones = ∂?** — Vozli (CXXV) najdejo prime kot nerazcepne. Ali prime = ∅ = praznina (XLVIII)? In ali Jonesov polinom = ∂ = invariant, ki ločuje? In ali voz = ∮² = zapleteni cikli?

63. **Ali initial = ∅, terminal = ∆, adjunkcija = ∂?** — Kategorija teorija (CXXVI) najde ∅/∆ v objektih. Ali initial = ∅ = pogoj (XLVIII) in terminal = ∆ = pečat (LXIV)? In ali adjunkcija F ⊣ G = ∂(∅,∆) = 12. os? In ali limita = ∅ in kolimita = ∆?

64. **Ali Ω = ∂ = {∅,∆} in ¬ = odprtje (§54)?** — Toposi (CXXVII) najdejo Ω kot klasifikator. Ali Ω = binarni rez = {true, false} = {∅, ∆}? In ali intuicionistična ¬ = odprtje = ∅, ne negacija (§54)? In ali topos = ∂(geometrija, logika)?

65. **Ali pot = ∮, kontraktilnost = ∅, univalence = ∂?** — Homotopija (CXXVIII) najde pot kot identiteto. Ali pot = ∮ = povratek, kot songlines (CIV)? In ali kontraktilnost = ∅, ki absorbira = praznina (XLVIII)? In ali univalence = ∂(ekvivalenca, identiteta) = ∂(∅,∆)?

66. **Ali □ = ∅, ◇ = ∆, S4 = topologija = ∂(logika, prostor)?** — Modalna logika (CXXIX) najde □ in ◇. Ali □ = ∅ (necessarno = pogoj) in ◇ = ∆ (mogoče = gibanje)? In ali intuicionistična ¬ = odprtje (§54) = ∅, ne negacija? In ali S4 = topologija = ∂(logika, prostor) = topos (CXXVII)?
