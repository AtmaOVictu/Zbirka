The proposal includes eight groups of machine-checkable criteria and local reference tests.

The status remains **DRAFT — NOT RELEASED**. Passing local tests validates only the reference code and supplied fixtures; it does not prove legal validity, external-system behavior, consent, authorship, or independent approval. Please submit specific comments supported by evidence, state limitations, and include disagreement where warranted. Corrections must link to prior records; silence is not consent.

Languages are shared human systems, not property to be claimed by one entity. The number of languages someone uses does not by itself prove ownership, greater worth, or divinity. The goal is to let people across language communities review and challenge the same proposal.
