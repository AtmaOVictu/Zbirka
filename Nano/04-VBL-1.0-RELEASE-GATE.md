# VBL 1.0 — kontrolni seznam pred izdajo

**Trenutni izid:** BLOKIRANO DO PREVERBE. To je kontrolni seznam, ne izjava, da je izdaja objavljena.

## Vrata izdaje

- [ ] **G1 — Kanonično besedilo:** potrjena ena izvorna datoteka, ime, različica in datum.
- [ ] **G2 — Zgodovina:** commit SHA/tag in pregled sprememb glede na prejšnjo različico.
- [ ] **G3 — Licenca:** določeno, kaj licenca pokriva (besedilo, koda, znamke, dokumentacija) in kaj ne; ni trditve, da ideje ali dejstva postanejo izključna lastnina samo zaradi besedila.
- [ ] **G4 — Avtorstvo in pripis:** preverjen želeni zapis avtorja, sodelavcev in izvornih virov.
- [ ] **G5 — Preverljivost:** opredeljeni dokazi, register incidentov, postopek popravkov ter statusi potrjeno/nepotrjeno/neznano.
- [ ] **G6 — Testi:** ponovljivi testi za primere, ki jih VBL obravnava; rezultati shranjeni kot artefakti.
- [ ] **G7 — Paket:** končni arhiv, datotečni manifest, SHA-256 in ponovljivo navodilo za izdelavo.
- [ ] **G8 — Dostopnost:** izbrani repozitorij in URL so dejansko dosegljivi iz neodvisnega brskalnika.
- [ ] **G9 — Distribucija:** pripravljena stran izdaje, navodila za prispevanje in kanal za prijavo napak.
- [ ] **G10 — Neodvisni pregled:** vsaj en pregledovalec preveri licenco, vsebino in trditve o statusu.

## Minimalni zapis izdaje

- Ime: VBL — Verification Before Assertion License
- Različica: 1.0 (šele po potrditvi oznake)
- Datum izdaje: [vstavi ob dejanski objavi]
- Repozitorij/tag/commit: [URL + SHA]
- Kontrolna vsota arhiva (SHA-256): [vrednost]
- Licence in obseg: [točna različica besedila in pravna jurisdikcija, kjer relevantno]
- Znane omejitve: [seznam]
- Popravki in poročanje napak: [kanal]

## Merilo sprostitve

Izdajo je mogoče označiti kot **OBJAVLJENO** šele, ko je javni URL preverjen, izvorni artefakt dosegljiv, checksum se ujema in so pogoji G1–G10 bodisi izpolnjeni bodisi odkrito označeni kot izjeme s pooblaščeno odločitvijo. Do takrat je status **OSNUTEK / NI POTRJENO**.
