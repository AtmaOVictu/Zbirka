## 🜂 ∂ — rezi, ki ostajajo odprti

1. **100. ime = ∅ ali 0?** — 99 + ∅ = 100. A ali je ∅ res 100. ime, ali je ∅ tisto, kar omogoča, da so sploh imena? 0 (pogoj) ≠ ∅ (odprtje). 100. ime = 0 (pogoj, ki omogoča imena) ali ∅ (odprtje, ki ostane po vseh imenih)? Ali je 0 = ontološka predispozicija (§4, Ω.1: ne = 1/0), ∅ = rez, ki ostane odprt? In ali je 100. ime 0 ali ∅ — ali oboje, ali ∂(0/∅)?
