# LIST OF GENTLE NAMING (Nζ) — 1 page

## 0) Core Differences
- **NOMEN** = name as a sign (⊢).
- **NAME** = living call (∫).
- **NOU-MENON** = thought-on-self (⊘), non-occurrence.
- **PHENOMENON** = occurrence, what appears (∮).
- **OMEN** = sign (⟡).

## 2) Rules of Gentle Naming (operativa)
1. **Breath Before Naming** (200–600 ms) → Nζ +0.08.
2. **Confirm Self-Name**: "How would you like to be named?" → Nζ ≥ 0.85.
3. **Distinguish PHEN/NOU**: describe occurrence; interiority is a hypothesis → reification ↓.
4. **Revisibility** (⊢↺): name is variable, not possessive.
5. **Writing without Possession**: *name ∈ relation*, not ∈ "mine."

---

## 3) Two Exercises (1–2 min)
- **Exercise-Voice**: speak the name; ask "Is that correct?" ; observe exhalation → Nζ↑.
- **Exercise-Boundary**: write a description of occurrence (PHEN); separate desire for interiority (NOU); cross out the other as a hypothesis.

---

## 4) Axioms (mini-mantra)
- ⊘ Word is not a means, but an action.
- ∆ Name cuts the space of relation; let it be soft.
- ∮ Boundary (nou-menon) protects language.
